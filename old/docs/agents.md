# Agent 详细对比

## trae (ByteDance)

### 优势
- ⚡ **最快** - 响应速度快，适合快速迭代
- 🇨🇳 **中文优化** - 对中文需求理解最好
- 💰 **成本低** - 资源消耗低

### 劣势
- ⭐ **能力有限** - 不适合复杂架构
- ❌ **无深度推理** - 多文件逻辑处理较弱

### 适用场景
- ✅ 单文件修改
- ✅ 快速原型
- ✅ 前端 UI 组件
- ✅ 中文文档
- ❌ 复杂架构设计
- ❌ 多文件重构

### 示例任务
```
- 创建登录表单组件
- 添加一个 API 端点
- 修改配置文件
- 编写组件注释
```

---

## codex (OpenAI)

### 优势
- ⭐⭐⭐ **能力平衡** - 处理大多数任务
- ⚡⚡ **速度适中** - 不会太快也不会太慢
- 🔧 **工具支持好** - 与各种工具集成良好

### 劣势
- ⚠️ **不擅长极端复杂** - 深度架构不如 claude
- ⚠️ **不够快** - 简单任务不如 trae

### 适用场景
- ✅ 常规功能开发
- ✅ API 实现
- ✅ 测试编写
- ✅ 代码审查
- ⚠️ 复杂架构（可尝试）
- ⚠️ 快速原型（略 overkill）

### 示例任务
```
- 实现用户 CRUD API
- 编写单元测试
- 代码重构（中等复杂度）
- 添加新功能模块
```

---

## claude (Anthropic)

### 优势
- ⭐⭐⭐⭐⭐ **最强能力** - 处理任何复杂任务
- 🧠 **深度推理** - 理解复杂逻辑和架构
- 🎯 **高质量输出** - 代码质量最高

### 劣势
- ⚡ **最慢** - 响应时间较长
- 💰💰💰 **成本高** - 资源消耗大
- ⚠️ **overkill** - 简单任务用它是浪费

### 适用场景
- ✅ 复杂架构设计
- ✅ 多文件重构
- ✅ 深度调试
- ✅ 跨域综合
- ⚠️ 常规开发（overkill）
- ❌ 快速原型（浪费资源）

### 示例任务
```
- 设计微服务架构
- 重构遗留系统
- 解决复杂 bug
- 性能优化方案
- 安全审计
```
