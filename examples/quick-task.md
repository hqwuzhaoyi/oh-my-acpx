## 分析

→ **类别: quick** → **Agent: trae**

## 执行

```json
sessions_spawn({
  runtime: "acp",
  agentId: "trae",
  mode: "run",
  streamTo: "parent",
  task: "创建一个 React 登录表单组件，包含邮箱和密码字段，带表单验证"
})
```

## 预期结果
